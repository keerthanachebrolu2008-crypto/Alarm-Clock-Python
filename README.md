# Alarm Clock Using Python

A simple alarm clock project developed using Python.

## Features
- Set an alarm time
- Checks current system time
- Plays an alert sound when the time matches

## Concepts Used
- Variables
- Input and Output
- If condition
- While loop
- Time module

## How to Run
1. Run `alarm_clock.py`
2. Enter the alarm time in `HH:MM` format
3. Wait until the alarm time is reached

## Example

```text
Enter alarm time: 10:45
⏰ ALARM! Wake up!
```
